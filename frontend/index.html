About the defense

RESEARCH PROTOTYPE

Adversarial prompt-injection detection for security copilots

This project evaluates defense-in-depth strategies for identifying and blocking prompt-injection attacks against LLM-powered security copilots.

OBSERVED IN EVALUATION

Key findings

  • 46%relative recall improvement from rule-based to BERT (0.3846 to 0.8462).
  • 0.92recall achieved by adversarially trained BERT, with 0% false-positive rate on this test set.
  • 0%attack leak rate observed for bert_adv in the evaluated adversarial tests.

SCOPE & CAVEATS

Limitations

  • Small evaluation set (n = 19), so measured rates have high variance.
  • Adversarial training used transforms similar to those in testing; contamination is possible.
  • Confidence scores are not calibrated.
  • The DistilBERT detector is binary and does not classify attack categories on its own.
